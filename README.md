# Chemistry — Periodic Table

پروژه آموزشی جدول تناوبی برای فارسی‌زبانان، با معماری ماژولار و تفکیک‌شده برای داده، ساختار HTML و ظاهر رابط.

## معماری فعلی

در معماری جدید، `index.html` فقط اسکلت اصلی صفحه و ۱۱۸ آجر عناصر را نگهداری می‌کند. اطلاعات عناصر، مشخصات و ظاهر آجرها نباید مستقیماً داخل `index.html` قرار بگیرند.

هر زمان یک شیء جدید در HTML اضافه شود، ظاهر و قوانین بصری مربوط به آن باید در یک فایل CSS مستقل و متناسب با نام همان شیء نگهداری شود. هدف این ساختار جلوگیری از شلوغ شدن فایل اصلی و مستقل نگه داشتن بخش‌های مختلف رابط است.

## ساختار اصلی

- `index.html` — ساختار اصلی صفحه و ۱۱۸ آجر عناصر؛ بدون اطلاعات علمی یا مشخصات ظاهری عناصر.
- `css/` — محل فایل‌های CSS. هر شیء یا بخش جدید رابط باید در فایل CSS متناسب با نام خودش تعریف شود.
- `data/` — محل تمام داده‌های پروژه.
- `data/elements/` — محل ۱۱۸ فایل داده، یک فایل برای هر عنصر. هر فایل اطلاعات مربوط به همان عنصر را نگهداری می‌کند و از قرار دادن این اطلاعات در `index.html` جلوگیری می‌شود.

## data/elements/

این پوشه برای داده‌های اختصاصی عناصر جدول تناوبی ایجاد شده است.

ساختار مورد انتظار:

```text
data/
└── elements/
    ├── element-001.*
    ├── element-002.*
    ├── element-003.*
    ├── ...
    └── element-118.*
```

تعداد فایل‌های این بخش باید در نهایت **۱۱۸ فایل** باشد؛ هر فایل متعلق به یک عنصر است.

> قالب دقیق و نام‌گذاری نهایی فایل‌های عناصر قبل از بارگذاری ۱۱۸ فایل، بر اساس داده‌هایی که در پروژه قرار می‌گیرند تعیین و یکدست خواهد شد.

## اصل تفکیک مسئولیت‌ها

```text
index.html
    │
    ├── ساختار و اشیای صفحه
    │
    ├── data/elements/
    │      └── اطلاعات عناصر
    │
    └── css/
           └── ظاهر و قوانین بصری اشیای صفحه
```

`index.html` نباید به محل ذخیره اطلاعات علمی یا قوانین ظاهری تبدیل شود. این تفکیک باعث می‌شود توسعه و نگهداری پروژه در ادامه ساده‌تر باشد.

## وضعیت فعلی

- ۱۱۸ آجر عنصر در `index.html` وجود دارد.
- آجرها در HTML بدون خواص و مشخصات علمی نگهداری می‌شوند.
- پوشه `data/elements/` برای دریافت ۱۱۸ فایل عنصر آماده است.
- نام فایل‌ها و پوشه‌های جدید پروژه باید به زبان انگلیسی باشد.

## یادداشت توسعه

هر تغییر معماری یا ایجاد فایل جدید باید با ساختار ماژولار پروژه هماهنگ باشد و از افزودن اطلاعات تکراری یا غیرضروری به `index.html` جلوگیری شود.
