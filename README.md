# Chemistry — Periodic Table

پروژه آموزشی جدول تناوبی برای فارسی‌زبانان، با معماری ماژولار و تفکیک‌شده برای ساختار HTML، داده و ظاهر رابط.

## معماری فعلی

`index.html` فقط اسکلت جدول و **۱۱۸ بلوک عنصر** را نگهداری می‌کند. اطلاعات نمایشی هر عنصر در زمان اجرا از فایل داده اختصاصی همان عنصر خوانده می‌شود.

ظاهر، رنگ‌بندی، اندازه و جانمایی بلوک‌ها در فایل CSS مستقل نگهداری می‌شود تا `index.html` شلوغ نشود.

منطق بارگذاری داده و ساخت محتوای کارت‌ها نیز در `js/element-cards.js` قرار دارد.

## ساختار اصلی

- `index.html` — ساختار اصلی صفحه و ۱۱۸ بلوک عنصر؛ بدون نام، نماد یا خواص علمی ثابت.
- `css/element-blocks.css` — جانمایی جدول، رنگ‌بندی دسته‌ها و ظاهر کارت‌های عناصر.
- `js/element-cards.js` — بارگذاری فایل JSON هر عنصر و قرار دادن شماره اتمی، نماد، نام انگلیسی و نام فارسی داخل کارت.
- `data/elements/` — محل فایل داده اختصاصی هر یک از ۱۱۸ عنصر.

## data/elements/

هر عنصر فایل داده مستقل خودش را دارد. فایل‌های فعلی از داده‌های PubChem PUG-View استفاده می‌کنند و نام‌گذاری آن‌ها بر اساس شماره اتمی است:

```text
data/
└── elements/
    ├── ELEMENT_ATOMIC NUMBER_1.json
    ├── ELEMENT_ATOMIC NUMBER_2.json
    ├── ELEMENT_ATOMIC NUMBER_3.json
    ├── ...
    └── ELEMENT_ATOMIC NUMBER_118.json
```

کد کارت هر عنصر فایل متناظر با `data-element` همان بلوک را فراخوانی می‌کند. شماره اتمی، نام انگلیسی و نماد از **فایل اختصاصی همان عنصر** استخراج می‌شوند.

## نام فارسی

داده‌های PubChem موجود در فایل‌های عنصر، نام فارسی را ارائه نمی‌کنند. بنابراین نام فارسی فعلاً در `js/element-cards.js` به‌صورت یک جدول نام‌گذاری رابط کاربری نگهداری شده است؛ این بخش بعداً می‌تواند به منبع داده فارسی مستقل منتقل شود، بدون اینکه داده خام PubChem تغییر کند.

## رنگ‌بندی

رنگ‌های کارت‌ها بر اساس تصویر مرجع ارائه‌شده برای پروژه تنظیم شده‌اند و در `css/element-blocks.css` قرار دارند. دسته‌ها شامل فلزات قلیایی، فلزات قلیایی خاکی، فلزات واسطه، فلزات پس‌واسطه، شبه‌فلزها، نافلزها، هالوژن‌ها، گازهای نجیب، لانتانوئیدها و اکتینیدها هستند.

## اصل تفکیک مسئولیت‌ها

```text
index.html
    │
    ├── 118 × element-block
    │
    ├── css/element-blocks.css
    │      ├── layout
    │      ├── position
    │      ├── colors
    │      └── card appearance
    │
    └── js/element-cards.js
           └── load data/elements/ELEMENT_ATOMIC NUMBER_*.json
```

`index.html` نباید محل ذخیره اطلاعات علمی یا قوانین ظاهری باشد. هر شیء جدیدی که به HTML اضافه می‌شود باید ظاهر مستقل خودش را در CSS متناسب با نام آن شیء داشته باشد.

## وضعیت فعلی

- ۱۱۸ بلوک عنصر در `index.html` وجود دارد.
- بلوک‌ها در ساختار HTML تعریف شده‌اند و محتوای کارت‌ها بعداً از داده بارگذاری می‌شود.
- فایل CSS مستقل، جانمایی جدول و رنگ‌بندی مشابه تصویر مرجع را کنترل می‌کند.
- فایل JavaScript هر کارت را از فایل JSON اختصاصی خودش پر می‌کند.
- نام فایل‌ها و پوشه‌های جدید پروژه باید به زبان انگلیسی باشد.

## یادداشت توسعه

هر تغییر معماری یا ایجاد فایل جدید باید با ساختار ماژولار پروژه هماهنگ باشد و از افزودن اطلاعات تکراری یا غیرضروری به `index.html` جلوگیری شود.
