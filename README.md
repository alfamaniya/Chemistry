# chemistry

مرجع داده‌های شیمی و رابط کاربری آموزشی پروژه.

## ساختار
- `data/Elements/` — داده‌های جداگانهٔ ۱۱۸ عنصر در قالب CSV
- `data/PubChemElements_all.csv` — مجموعهٔ یکپارچهٔ داده‌های عناصر
- `data/ELEMENTS_118_ADVANCED.csv` — داده‌های سطح حرفه‌ای
- `data/ELEMENTS_118_VERY_ADVANCED.csv` — داده‌های سطح پیشرفته
- `index.html` — صفحهٔ اصلی دوزبانه (فارسی/English)
- `assets/css/main.css` — استایل موبایل‌محور و واکنش‌گرا
- `assets/js/main.js` — منطق زبان، بارگذاری CSV و ساخت جدول تناوبی مطابق چیدمان مرجع PDF

## بررسی خودکار (GitHub Actions)\n\nفایل `.github/workflows/webpack.yml` برای این پروژه به‌صورت یک سایت استاتیک بررسی می‌شود و به `package.json` یا Webpack وابسته نیست. این workflow وجود فایل‌های اصلی، صحت نحوی JavaScript و دسترسی HTTP به صفحه و فایل JavaScript را بررسی می‌کند.\n\n## اجرای محلی
به دلیل استفاده از `fetch` برای خواندن CSV، فایل `index.html` را مستقیماً با `file://` باز نکنید. یک وب‌سرور ساده اجرا کنید:
```bash
python -m http.server 8000
```
سپس به `http://localhost:8000` بروید.

## رابط کاربری
صفحه با تمرکز بر موبایل طراحی شده و شامل:
- رابط دوزبانهٔ فارسی و انگلیسی با تغییر جهت RTL/LTR
- ذخیرهٔ زبان انتخاب‌شده در مرورگر
- هدر و توضیحات
- جدول تناوبی با کارت‌های مربعی و گوشه‌های نرم
- اطلاعات مبتدی، پیشرفته و فوق پیشرفته برای عنصر انتخاب‌شده
- فوتر و لینک بازگشت به بالا

جدول تناوبی به‌صورت پویا از `data/PubChemElements_all.csv` خوانده می‌شود و ستون `NameFa` نام فارسی هر ۱۱۸ عنصر را در اختیار رابط کاربری قرار می‌دهد؛ با تغییر زبان، نام عناصر جدول نیز بین فارسی و انگلیسی جابه‌جا می‌شود. چیدمان اصلی بر پایهٔ جدول ۱۸ گروهی صفحهٔ مرجع PDF است؛ عناصر ۵۷–۷۱ و ۸۹–۱۰۳ در دو ردیف مجزا از زیر گروه ۳ قرار می‌گیرند. در نمایش موبایل، جدول با عرض حداقلی کنترل‌شده و اسکرول افقی خوانا باقی می‌ماند.

پس از انتخاب هر عنصر، یک کادر اطلاعات مختصر و سپس سه کادر اطلاعاتی نمایش داده می‌شود:
- مبتدی: از همان ردیف عنصر در `data/PubChemElements_all.csv`
- پیشرفته: از `data/ELEMENTS_118_ADVANCED.csv`
- فوق پیشرفته: از `data/ELEMENTS_118_VERY_ADVANCED.csv`

هدر/بخش معرفی صفحه و جدول از یک عرض مشترک استفاده می‌کنند تا با جدول تناوبی هم‌تراز باشند.


## رنگ‌بندی جدول بر اساس PDF
فایل images-to-pdf-2026-09-23.pdf شامل ۱۵ تصویر جدول تناوبی است. در بالای جدول تناوبی یک فهرست کشویی با ۱۵ گزینه مطابق موضوع هر تصویر اضافه شده است. با انتخاب هر گزینه، رنگ‌بندی کارت‌های جدول به پالت رنگی همان صفحهٔ PDF نزدیک می‌شود.

- انتخاب ۱: جرم اتمی
- انتخاب ۲: چگالی
- انتخاب ۳: حالت استاندارد
- انتخاب ۴: الکترونگاتیویته
- انتخاب ۵: انرژی یونش
- انتخاب ۶: آرایش الکترونی
- انتخاب ۷: شعاع اتمی
- انتخاب ۸: حالت‌های اکسایش
- انتخاب ۹: الکترون‌خواهی
- انتخاب ۱۰: نقطه ذوب
- انتخاب ۱۱: نقطه جوش
- انتخاب ۱۲: اشغال اوربیتال
- انتخاب ۱۳: فلز / شبه‌فلز / نافلز
- انتخاب ۱۴: پایداری شیمیایی
- انتخاب ۱۵: گروه / خانواده شیمیایی

انتخاب رنگ در localStorage مرورگر ذخیره می‌شود و با تغییر زبان، عنوان گزینه‌ها نیز بین فارسی و انگلیسی جابه‌جا می‌شود.
