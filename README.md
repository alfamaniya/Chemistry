# chemistry

مرجع داده‌های شیمی و رابط کاربری آموزشی پروژه.

## ساختار
- `data/Elements/` — داده‌های جداگانهٔ ۱۱۸ عنصر در قالب CSV
- `data/PubChemElements_all.csv` — مجموعهٔ یکپارچهٔ داده‌های عناصر
- `data/ELEMENTS_118_BEGINNER.csv` — داده‌های سطح مبتدی
- `data/ELEMENTS_118_ADVANCED.csv` — داده‌های سطح حرفه‌ای
- `data/ELEMENTS_118_VERY_ADVANCED.csv` — داده‌های سطح پیشرفته
- `index.html` — صفحهٔ اصلی دوزبانه (فارسی/English)
- `assets/css/main.css` — استایل موبایل‌محور و واکنش‌گرا
- `assets/js/main.js` — منطق زبان، بارگذاری CSV و ساخت جدول تناوبی مطابق چیدمان مرجع PDF

## اجرای محلی
به دلیل استفاده از `fetch` برای خواندن CSV، فایل `index.html` را مستقیماً با `file://` باز نکنید. یک وب‌سرور ساده اجرا کنید:
```bash
python -m http.server 8000
```
سپس به `http://localhost:8000` بروید.

## رابط کاربری
صفحه با تمرکز بر موبایل طراحی شده و شامل:
- رابط دوزبانهٔ فارسی و انگلیسی با تغییر جهت RTL/LTR
- ذخیرهٔ زبان انتخاب‌شده در مرورگر
- هدر و توضیحات
- جدول تناوبی با کارت‌های مربعی و گوشه‌های نرم
- سه مسیر اطلاعاتی مبتدی، حرفه‌ای و پیشرفته
- فوتر و لینک بازگشت به بالا

جدول تناوبی به‌صورت پویا از `data/PubChemElements_all.csv` خوانده می‌شود. چیدمان اصلی بر پایهٔ جدول ۱۸ گروهی صفحهٔ مرجع PDF است؛ عناصر ۵۷–۷۱ و ۸۹–۱۰۳ در دو ردیف مجزا از زیر گروه ۳ قرار می‌گیرند. در نمایش موبایل، جدول با عرض حداقلی کنترل‌شده و اسکرول افقی خوانا باقی می‌ماند.
