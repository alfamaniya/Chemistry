# Chemistry

## ساختار چندزبانه

سیستم زبان سایت به‌صورت متمرکز مدیریت می‌شود و در حال حاضر از فارسی (`fa`) و انگلیسی (`en`) پشتیبانی می‌کند.

### فایل‌های زبان

- `locales/fa.json` — تمام متن‌ها و برچسب‌های فارسی رابط کاربری.
- `locales/en.json` — تمام متن‌ها و برچسب‌های انگلیسی رابط کاربری.
- `scripts/site-preferences.js` — بارگذاری و اعمال فایل زبان، تغییر جهت `RTL/LTR` و ذخیره زبان انتخاب‌شده در `localStorage`.

برای اضافه‌کردن متن جدید به سایت، ابتدا کلید متن در هر دو فایل locale تعریف شود و سپس در HTML با `data-i18n` استفاده شود. برای برچسب‌های دسترسی نیز از `data-i18n-aria-label` استفاده شود.

## جدول تناوبی

باکس بعد از جستجو به‌عنوان جدول تناوبی عناصر استفاده می‌شود و ساختار آن بر اساس چیدمان استاندارد ۱۸ گروه و ۷ دوره پیاده‌سازی شده است.

- `data/elements-index.json` — منبع ۱۱۸ عنصر با عدد اتمی، نماد، نام انگلیسی و نام فارسی.
- `scripts/periodic-table.js` — ساخت کارت‌های ۱۱۸ عنصر، جایگذاری در گروه/دوره صحیح، مدیریت لانتانیدها و اکتینیدها و تعویض نام فارسی/انگلیسی.
- `styles/periodic-table.css` — چیدمان واکنش‌گرا، رنگ‌بندی دسته‌های عناصر، کارت‌ها و حالت تاریک جدول.
- جدول از نظر ساختار شیمیایی همیشه `LTR` است تا ترتیب گروه‌ها و نمادهای عناصر ثابت بماند؛ نام عنصر بر اساس زبان صفحه تغییر می‌کند.
- در موبایل جدول داخل ناحیه اسکرول افقی قرار می‌گیرد تا کارت‌ها فشرده یا بریده نشوند.

## داده عناصر

پوشه `data/` شامل ۱۱۸ فایل JSON مستقل، یک فایل برای هر عنصر بر اساس عدد اتمی است. ساختار منبع از یک `Record` با بخش‌های تو در تو و آیتم‌های `Information` تشکیل شده است؛ نمونه منبع هیدروژن شامل بخش‌های `Identifiers` و `Properties` و ویژگی‌هایی مانند نام عنصر، نماد، InChI، جرم اتمی، آرایش الکترونی، شعاع اتمی، حالت‌های اکسایش، انرژی یونش و الکترونگاتیویته است.

### لایه تحلیل داده

- `data/analyzed/` — لایه مشتق‌شده برای ایندکس و تحلیل داده‌های ۱۱۸ عنصر؛ فایل‌های اصلی در `data/` دست‌نخورده می‌مانند.
- `data/analyzed/elements-index.json` — فهرست استاندارد ۱۱۸ عنصر و اتصال هر عنصر به فایل منبع خودش.
- `data/analyzed/README.md` — تعریف مدل نرمال‌شده تحلیل.
- `scripts/build-element-analysis.mjs` — اسکریپت تحلیل تکرارپذیر که تمام ۱۱۸ فایل را پیمایش می‌کند، بخش‌ها و تعداد آیتم‌های اطلاعاتی را استخراج می‌کند و وجود مراجع را تشخیص می‌دهد.

اجرای تحلیل از ریشه پروژه:

```bash
node scripts/build-element-analysis.mjs
```

اسکریپت در صورتی که دقیقاً ۱۱۸ فایل عنصر پیدا نکند متوقف می‌شود تا از ناقص‌شدن ایندکس جلوگیری شود.

### ساختار فعلی

- `index.html` — نقطه ورود صفحه و اتصال قابلیت‌ها.
- `components/` — اجزای مستقل رابط کاربری.
- `styles/` — فایل‌های CSS تفکیک‌شده برای قابلیت‌ها و قوانین RTL/LTR.
- `scripts/` — منطق تعاملی، تنظیمات سایت و ابزار تحلیل داده.
- `locales/` — فرهنگ لغات زبان‌های پشتیبانی‌شده.
- `data/` — داده خام عناصر، ایندکس عناصر و لایه تحلیل داده.

### استاندارد زبان

- فارسی و عربی با جهت `RTL` نمایش داده می‌شوند.
- انگلیسی با جهت `LTR` نمایش داده می‌شود.
- متن‌های ترکیبی از قوانین دوطرفه (`bidi`) استفاده می‌کنند.
- زبان انتخاب‌شده در مرورگر ذخیره می‌شود و در مراجعه بعدی حفظ خواهد شد.
