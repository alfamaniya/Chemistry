# Chemistry — Periodic Table

پروژه آموزشی و تعاملی جدول تناوبی عناصر.

## وضعیت فعلی

- جدول شامل ۱۱۸ `element` است.
- اطلاعات کارت‌ها از `data/PubChemElements_all.csv` خوانده می‌شود.
- نمایش کارت شامل عدد اتمی، نماد، نام فارسی و نام انگلیسی است.
- کلیک روی هر کارت، انیمیشن چشمک نرم و دو مرحله‌ای اجرا می‌کند.
- طراحی جدول برای نمایش در موبایل بهینه شده است.
- برای جدول و کادر معرفی، پس‌زمینه و کادر خنثی با گوشه‌های نرم ایجاد شده است.
- کادر معرفی سایت در بالای جدول قرار دارد.

## داده‌ها

```text
 data/
 ├── PubChemElements_all.csv
 ├── elements_basic.csv
 ├── periodic_table_properties.csv
 └── elements/
     └── فایل‌های اختصاصی ۱۱۸ عنصر
```

**مهم:** فایل‌های اصلی عناصر منبع هستند و بدون دستور صریح نباید اطلاعات آن‌ها حذف یا بازنویسی شود.

## ساختار کد

```text
index.html                 ساختار صفحه و ۱۱۸ کارت
css/periodic-table.css     ظاهر، رنگ‌بندی و جانمایی جدول
js/periodic-table.js       بارگذاری CSV و رفتار کارت‌ها
data/                      داده‌های عناصر
```

## نکات برای توسعه‌دهندگان بعدی

- قبل از تغییر، وضعیت واقعی مخزن و `conversation_history.txt` بررسی شود.
- اطلاعات عنصر داخل HTML به‌صورت ثابت نوشته نشود؛ از فایل‌های داده خوانده شود.
- برای تغییر ظاهر، CSS مربوط به همان بخش تغییر کند و از شلوغ کردن `index.html` خودداری شود.
- داده‌های موجود بدون درخواست صریح حذف یا بازنویسی نشوند.
- نام فایل‌ها و پوشه‌های جدید انگلیسی باشد.

## خلاصه آخرین توسعه

جدول به‌صورت موبایل‌محور بازطراحی شد، کارت‌های عناصر ظاهر نرم و منحصر‌به‌فرد گرفتند، کادر معرفی بالای جدول اضافه شد و جانمایی ۱۱۸ عنصر پس از به‌هم‌ریختگی CSS اصلاح شد. در مرحله بعد می‌توان طراحی پس‌زمینه اصلی صفحه را توسعه داد؛ نمونه بصری با حال‌وهوای پاییزی و پویا تهیه شده، اما هنوز به کد سایت اعمال نشده است.
